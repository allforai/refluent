# Global Suggestion Overlay Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the per-pane refluent status line with one macOS floating panel that pops up only when a new suggestion arrives, never takes focus, and can be dragged to a remembered position.

**Architecture:** A long-lived Node process (`refluent overlay run`, started by a LaunchAgent) polls the existing SQLite store once a second, decides what is new, and sends one JSON line per suggestion to a small Swift/AppKit helper that only renders. The helper reports drags back as JSON lines; Node stores the position. Installing the overlay turns the existing `statusline-suggestion` preference off; uninstalling restores it.

**Tech Stack:** TypeScript (Node ≥ 22, ESM), better-sqlite3, vitest; Swift 5 language mode compiled with `xcrun swiftc`, AppKit only; macOS `launchctl`.

**Spec:** `docs/superpowers/specs/2026-09-24-overlay-design.md`

## Global Constraints

- macOS only. The helper is compiled with `xcrun swiftc -O -swift-version 5 <source> -o <binary>`; no Xcode project, no third-party Swift packages.
- Hooks, capture and analysis code are not modified.
- Freshness is the existing `STATUSLINE_TTL_MS` (15 minutes) via `isFresh` from `src/statusline.ts`.
- `overlay-duration` is a preference with allowed values `6`, `12`, `20`, `30`, `60` (seconds), default `12`.
- Overlay payload fields are capped at 300 display columns each (`OVERLAY_FIELD_MAX_COLUMNS = 300`) and stripped of control characters.
- Crash-loop threshold: 5 helper exits within 60 s stops the helper; restart backoff is 1 s, doubling, capped at 30 s.
- Helper binary: `<dataDir>/bin/refluent-overlay`. LaunchAgent: `~/Library/LaunchAgents/com.refluent.overlay.plist`, label `com.refluent.overlay`. Log: `<dataDir>/overlay.log`.
- Paths in the LaunchAgent are absolute: `process.execPath` and the absolute `bin/refluent`, the way hooks are registered.
- A missing `swiftc` aborts `overlay install` before anything is changed and names `xcode-select --install`.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.

## Review Focus

1. **Installing twice** — the second install must not record `off` as the "previous" status-line value; uninstall must still restore the user's original value. (Test in Task 3.)
2. **Several suggestions within one poll tick** — only the newest is shown, and none of the older ones pops up on the next tick. (Test in Task 1.)
3. **Database busy or closed during a poll** — the tick is skipped and the runner keeps going; it never throws out of the interval. (Test in Task 2.)
4. **Helper binary missing or unlaunchable at run time** (deleted, not yet compiled) — spawn errors count as exits, the supervisor stops after the crash-loop threshold and reports `stopped`, and nothing throws. (Test in Task 2.)
5. **Helper stdout split across chunks or containing garbage** — only complete, well-formed lines are applied; malformed ones are ignored. (Tests in Tasks 1 and 2.)

```ts
import type { DatabaseType } from './db.js';
import { nowIso } from './config.js';
import { getLastAnalysisResult, getSetting, quietModeOn, setSetting } from './settings.js';
import { issueClassLabel, isIssueClass } from './issue-classes.js';
import { cutToWidth, isFresh, latestSuggestion, type Suggestion } from './statusline.js';

/**
 * Decisions for the floating overlay. Everything here is synchronous and reads or writes
 * only the settings table, so the process shell (`overlay-runner.ts`) stays dumb and
 * this stays testable against an in-memory database.
 */

/** The panel is wider than a terminal row, but no field may grow without bound. */
export const OVERLAY_FIELD_MAX_COLUMNS = 300;

export const LAST_SHOWN_ID_KEY = 'overlay-last-shown-id';
export const LAST_FAILURE_AT_KEY = 'overlay-last-failure-at';
export const POSITION_KEY = 'overlay-position';
export const TEST_REQUEST_KEY = 'overlay-test-request';
export const STATUS_KEY = 'overlay_status';
export const HEARTBEAT_KEY = 'overlay_heartbeat_at';
/** The runner beats every 10 s; three missed beats means it is not running. */
export const HEARTBEAT_STALE_MS = 30_000;

const DEFAULT_DURATION_SECONDS = 12;

export interface OverlayPosition {
  x: number;
  y: number;
}

export interface ShowMessage {
  type: 'show';
  rewrite: string;
  label: string;
  reason: string;
  original: string;
  durationMs: number;
  position: OverlayPosition | null;
}

export type HelperMessage = { type: 'moved'; x: number; y: number } | { type: 'dismissed' };

export type OverlayStatus = 'running' | 'stopped' | 'not_installed';

const SAMPLE_SUGGESTION: Suggestion = {
  instanceId: 0,
  original: 'Please help me check this code whether has bug.',
  rewrite: 'Please check whether this code has a bug.',
  reason: 'Keep statement order after "whether".',
  issueClass: 'grammar_error',
  createdAt: '',
};

function isFiniteNumber(value: unknown): value is number {
  return typeof value === 'number' && Number.isFinite(value);
}

function field(text: string): string {
  return cutToWidth(text, OVERLAY_FIELD_MAX_COLUMNS);
}

function durationMs(db: DatabaseType): number {
  const seconds = Number(getSetting(db, 'overlay-duration') ?? DEFAULT_DURATION_SECONDS);
  return (Number.isFinite(seconds) && seconds > 0 ? seconds : DEFAULT_DURATION_SECONDS) * 1000;
}

export function readPosition(db: DatabaseType): OverlayPosition | null {
  const raw = getSetting(db, POSITION_KEY);
  if (!raw) return null;
  try {
    const parsed = JSON.parse(raw) as Record<string, unknown> | null;
    return parsed && isFiniteNumber(parsed.x) && isFiniteNumber(parsed.y) ? { x: parsed.x, y: parsed.y } : null;
  } catch {
    return null;
  }
}

export function buildShowMessage(db: DatabaseType, suggestion: Suggestion): ShowMessage {
  const label = isIssueClass(suggestion.issueClass) ? issueClassLabel(suggestion.issueClass) : 'issue';
  return {
    type: 'show',
    rewrite: field(suggestion.rewrite),
    label,
    // A translation's reason only repeats its label, as on the status line.
    reason: suggestion.issueClass === 'chinese_translation' ? '' : field(suggestion.reason),
    original: field(suggestion.original),
    durationMs: durationMs(db),
    position: readPosition(db),
  };
}

function failureMessage(db: DatabaseType): ShowMessage {
  return {
    type: 'show',
    rewrite: 'analysis unavailable',
    label: 'refluent',
    reason: 'run `refluent settings`',
    original: '',
    durationMs: durationMs(db),
    position: readPosition(db),
  };
}

/** Asks the running overlay to show the sample suggestion on its next poll. */
export function requestTestOverlay(db: DatabaseType, now: Date = new Date()): void {
  setSetting(db, TEST_REQUEST_KEY, nowIso(now));
}

/**
 * What the overlay should show now, if anything. Advances the stored cursors, so each
 * suggestion and each failure is shown at most once — including in quiet mode, where the
 * backlog is skipped rather than replayed when quiet mode ends.
 */
export function nextOverlayMessage(db: DatabaseType, now: Date = new Date()): ShowMessage | null {
  if (getSetting(db, TEST_REQUEST_KEY)) {
    setSetting(db, TEST_REQUEST_KEY, '');
    return buildShowMessage(db, SAMPLE_SUGGESTION);
  }

  const suggestion = latestSuggestion(db);
  const last = getLastAnalysisResult(db);
  const storedId = getSetting(db, LAST_SHOWN_ID_KEY);
  if (!storedId) {
    // First poll ever: what already exists was seen on the status line, not news.
    setSetting(db, LAST_SHOWN_ID_KEY, String(suggestion?.instanceId ?? 0));
    if (last?.outcome === 'failed') setSetting(db, LAST_FAILURE_AT_KEY, last.at);
    return null;
  }

  let message: ShowMessage | null = null;
  if (suggestion && suggestion.instanceId > Number(storedId)) {
    setSetting(db, LAST_SHOWN_ID_KEY, String(suggestion.instanceId));
    if (isFresh(suggestion.createdAt, now)) message = buildShowMessage(db, suggestion);
  }
  if (!message && last?.outcome === 'failed' && last.at !== getSetting(db, LAST_FAILURE_AT_KEY)) {
    setSetting(db, LAST_FAILURE_AT_KEY, last.at);
    if (isFresh(last.at, now)) message = failureMessage(db);
  }
  return quietModeOn(db) ? null : message;
}

/** One line from the helper's stdout; anything malformed is ignored, never thrown. */
export function parseHelperLine(line: string): HelperMessage | null {
  let value: unknown;
  try {
    value = JSON.parse(line);
  } catch {
    return null;
  }
  if (typeof value !== 'object' || value === null || Array.isArray(value)) return null;
  const record = value as Record<string, unknown>;
  if (record.type === 'moved' && isFiniteNumber(record.x) && isFiniteNumber(record.y)) {
    return { type: 'moved', x: record.x, y: record.y };
  }
  if (record.type === 'dismissed') return { type: 'dismissed' };
  return null;
}

export function applyHelperMessage(db: DatabaseType, message: HelperMessage): void {
  if (message.type === 'moved') {
    setSetting(db, POSITION_KEY, JSON.stringify({ x: message.x, y: message.y }));
  }
}

/** `installed` is whether the LaunchAgent exists; the runner records the rest. */
export function overlayStatus(db: DatabaseType, installed: boolean, now: Date = new Date()): OverlayStatus {
  if (!installed) return 'not_installed';
  if (getSetting(db, STATUS_KEY) !== 'running') return 'stopped';
  const beat = Date.parse(getSetting(db, HEARTBEAT_KEY) ?? '');
  return Number.isFinite(beat) && now.getTime() - beat <= HEARTBEAT_STALE_MS ? 'running' : 'stopped';
}
```

```ts
import { EventEmitter } from 'node:events';
import { PassThrough } from 'node:stream';
import { afterEach, beforeEach, describe, expect, it } from 'vitest';
import { memoryDb, seedPoint } from './helpers.js';
import type { DatabaseType } from '../src/db.js';
import { getSetting } from '../src/settings.js';
import { POSITION_KEY, applyHelperMessage, nextOverlayMessage, parseHelperLine } from '../src/overlay.js';
import { CRASH_LOOP_LIMIT, HelperSupervisor, overlayTick, type HelperProcess } from '../src/overlay-runner.js';

class FakeHelper extends EventEmitter {
  stdin = new PassThrough();
  stdout = new PassThrough();
  written: string[] = [];
  killed = false;
  constructor() {
    super();
    this.stdin.on('data', (chunk) => this.written.push(String(chunk)));
  }
  kill(): boolean {
    this.killed = true;
    return true;
  }
}

interface Harness {
  supervisor: HelperSupervisor;
  helpers: FakeHelper[];
  lines: string[];
  stopped: string[];
  pending: Array<{ fn: () => void; ms: number }>;
  clock: { t: number };
  spawnThrows: { value: boolean };
}

function harness(): Harness {
  const helpers: FakeHelper[] = [];
  const lines: string[] = [];
  const stopped: string[] = [];
  const pending: Array<{ fn: () => void; ms: number }> = [];
  const clock = { t: 0 };
  const spawnThrows = { value: false };
  const supervisor = new HelperSupervisor({
    spawnHelper: () => {
      if (spawnThrows.value) throw new Error('ENOENT');
      const helper = new FakeHelper();
      helpers.push(helper);
      return helper as unknown as HelperProcess;
    },
    onLine: (line) => lines.push(line),
    onStopped: (reason) => stopped.push(reason),
    now: () => clock.t,
```

```ts
import { spawn } from 'node:child_process';
import readline from 'node:readline';
import type { DatabaseType } from './db.js';
import { nowIso } from './config.js';
import { setSetting } from './settings.js';
import { HEARTBEAT_KEY, STATUS_KEY, applyHelperMessage, nextOverlayMessage, parseHelperLine } from './overlay.js';

/** The slice of a child process the supervisor uses; a test passes a fake. */
export interface HelperProcess {
  stdin: NodeJS.WritableStream | null;
  stdout: NodeJS.ReadableStream | null;
  on(event: 'exit', listener: (code: number | null) => void): unknown;
  on(event: 'error', listener: (error: Error) => void): unknown;
  kill(): boolean;
}

export const CRASH_LOOP_LIMIT = 5;
export const CRASH_LOOP_WINDOW_MS = 60_000;
export const MAX_BACKOFF_MS = 30_000;
const POLL_MS = 1000;
const HEARTBEAT_MS = 10_000;

export interface SupervisorOptions {
  spawnHelper: () => HelperProcess;
  onLine: (line: string) => void;
  onStopped: (reason: string) => void;
  now?: () => number;
  schedule?: (fn: () => void, ms: number) => void;
}

/**
 * Keeps the Swift helper alive: restarts it with a doubling backoff, and gives up after
 * `CRASH_LOOP_LIMIT` exits inside `CRASH_LOOP_WINDOW_MS` so a broken binary cannot spin.
 */
export class HelperSupervisor {
  private child: HelperProcess | null = null;
  private exits: number[] = [];
  private stopped = false;

  constructor(private readonly options: SupervisorOptions) {}

  get isStopped(): boolean {
    return this.stopped;
  }

  start(): void {
    if (!this.stopped) this.launch();
  }

  send(message: object): void {
    this.child?.stdin?.write(`${JSON.stringify(message)}\n`);
  }

  shutdown(): void {
    this.stopped = true;
    this.child?.kill();
    this.child = null;
  }

  private launch(): void {
    let child: HelperProcess;
    try {
      child = this.options.spawnHelper();
    } catch (error) {
      this.handleExit(error instanceof Error ? error.message : String(error));
      return;
    }
    this.child = child;
    let settled = false;
    // `error` and `exit` can both fire for one process; it is one exit.
    const done = (reason: string) => {
      if (settled) return;
      settled = true;
      if (this.child === child) this.child = null;
      this.handleExit(reason);
    };
    child.on('error', (error) => done(error.message));
    child.on('exit', (code) => done(`exit ${code}`));
    if (child.stdout) readline.createInterface({ input: child.stdout }).on('line', this.options.onLine);
  }

  private handleExit(reason: string): void {
    if (this.stopped) return;
    const now = (this.options.now ?? Date.now)();
    this.exits = [...this.exits.filter((t) => now - t < CRASH_LOOP_WINDOW_MS), now];
    if (this.exits.length >= CRASH_LOOP_LIMIT) {
      this.stopped = true;
      this.options.onStopped(reason);
      return;
    }
    const delay = Math.min(MAX_BACKOFF_MS, 1000 * 2 ** (this.exits.length - 1));
    const schedule = this.options.schedule ?? ((fn, ms) => void setTimeout(fn, ms));
    schedule(() => {
      if (!this.stopped) this.launch();
    }, delay);
  }
}

export function spawnHelperProcess(binaryPath: string): HelperProcess {
  const child = spawn(binaryPath, [], { stdio: ['pipe', 'pipe', 'inherit'] });
  // A write racing the helper's exit raises EPIPE on stdin; the exit is handled above.
  child.stdin.on('error', () => undefined);
  return child;
}

/** One poll. A busy or closed database skips the tick; the loop must never throw. */
export function overlayTick(db: DatabaseType, sink: { send(message: object): void }, now: Date = new Date()): void {
  try {
    const message = nextOverlayMessage(db, now);
    if (message) sink.send(message);
  } catch {
    // Skip this tick; the next one retries.
  }
}

function safeSet(db: DatabaseType, key: string, value: string): void {
  try {
    setSetting(db, key, value);
  } catch {
    // Status is advisory; a busy database must not stop the overlay.
  }
}

/** The long-lived process behind the LaunchAgent. Resolves 0 on SIGTERM or crash loop. */
export function runOverlay(db: DatabaseType, binaryPath: string, log: (line: string) => void): Promise<number> {
  return new Promise((resolve) => {
    let lastBeat = 0;
    const beat = () => {
      lastBeat = Date.now();
      safeSet(db, HEARTBEAT_KEY, nowIso());
    };
    const supervisor = new HelperSupervisor({
      spawnHelper: () => spawnHelperProcess(binaryPath),
      onLine: (line) => {
        const message = parseHelperLine(line);
        if (!message) return;
        try {
          applyHelperMessage(db, message);
        } catch {
          // A lost position is not worth crashing over.
        }
      },
      onStopped: (reason) => {
        log(`${nowIso()} overlay helper stopped after repeated exits: ${reason}`);
        safeSet(db, STATUS_KEY, 'stopped');
        finish();
      },
    });
    const timer = setInterval(() => {
      overlayTick(db, supervisor);
      if (Date.now() - lastBeat >= HEARTBEAT_MS) beat();
    }, POLL_MS);
    const finish = () => {
      clearInterval(timer);
      supervisor.shutdown();
      resolve(0);
    };
    process.once('SIGTERM', finish);
    process.once('SIGINT', finish);
    safeSet(db, STATUS_KEY, 'running');
    beat();
    supervisor.start();
  });
}
```

```ts
/** The `statusline-suggestion` value from before the overlay turned it off. */
export const PREV_STATUSLINE_KEY = 'overlay-prev-statusline-suggestion';

  source: string;
  binary: string;
  plist: string;
  log: string;

export const runCommand: CommandRunner = (command, args) => {
  const result = spawnSync(command, args, { encoding: 'utf8' });
  return {
    status: result.status ?? 1,
    output: `${result.stdout ?? ''}${result.stderr ?? ''}${result.error ? result.error.message : ''}`,
  };
};

export interface OverlayInstallOptions {
  paths: OverlayPaths;
  run: CommandRunner;
  nodePath: string;
  binPath: string;
  uid: number;
  dataDirOverride: string | null;
  platform?: NodeJS.Platform;

export interface OverlayInstallResult {
  ok: boolean;
  messages: string[];

function xml(text: string): string {
  return text.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;');
}

/**
 * The LaunchAgent starts the runner at login and restarts it only after a crash: a clean
 * exit (SIGTERM, or the supervisor giving up on a broken helper) is left stopped.
 */
export function buildPlist(options: {
  nodePath: string;
  binPath: string;
  logPath: string;
  dataDirOverride: string | null;
}): string {
  const env = options.dataDirOverride
    ? `
  <key>EnvironmentVariables</key>
  <dict>
    <key>REFLUENT_DATA_DIR</key>
    <string>${xml(options.dataDirOverride)}</string>
  </dict>`
    : '';
  return `<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key>
  <string>${OVERLAY_LABEL}</string>
  <key>ProgramArguments</key>
  <array>
    <string>${xml(options.nodePath)}</string>
    <string>${xml(options.binPath)}</string>
    <string>overlay</string>
    <string>run</string>
  </array>
  <key>RunAtLoad</key>
  <true/>
  <key>KeepAlive</key>
  <dict>
    <key>SuccessfulExit</key>
    <false/>
  </dict>
  <key>StandardErrorPath</key>
  <string>${xml(options.logPath)}</string>${env}
</dict>
</plist>
`;
}

export function installOverlay(db: DatabaseType, options: OverlayInstallOptions): OverlayInstallResult {
  if ((options.platform ?? process.platform) !== 'darwin') {
    return { ok: false, messages: ['The overlay is macOS only. Nothing was changed.'] };
  }
  const { paths, run } = options;
  if (run('xcrun', ['--find', 'swiftc']).status !== 0) {
    return {
      ok: false,
      messages: ['swiftc was not found. Run `xcode-select --install`, then retry. Nothing was changed.'],
    };
  }
  fs.mkdirSync(path.dirname(paths.binary), { recursive: true });
  const compile = run('xcrun', ['swiftc', '-O', '-swift-version', '5', paths.source, '-o', paths.binary]);
  if (compile.status !== 0) {
    return {
      ok: false,
      messages: ['Could not compile the overlay helper. Nothing else was changed.', compile.output.trim()],
    };
  }
  fs.mkdirSync(path.dirname(paths.plist), { recursive: true });
  fs.writeFileSync(
    paths.plist,
    buildPlist({
      nodePath: options.nodePath,
      binPath: options.binPath,
      logPath: paths.log,
      dataDirOverride: options.dataDirOverride,
    }),
    'utf8',
  );
  // A reinstall replaces the running agent; the first install has nothing to stop.
  run('launchctl', ['bootout', `gui/${options.uid}/${OVERLAY_LABEL}`]);
  const boot = run('launchctl', ['bootstrap', `gui/${options.uid}`, paths.plist]);
  if (boot.status !== 0) {
    return {
      ok: false,
      messages: [
        `launchctl could not start the overlay: ${boot.output.trim()}`,
        'The terminal status line was left unchanged.',
      ],
    };
  }
  if (!getSetting(db, PREV_STATUSLINE_KEY)) {
    setSetting(db, PREV_STATUSLINE_KEY, getSetting(db, 'statusline-suggestion') ?? 'on');
  }
  setSetting(db, 'statusline-suggestion', 'off');
  return {
    ok: true,
    messages: [
      `Overlay helper compiled: ${paths.binary}`,
      `LaunchAgent written and started: ${paths.plist}`,
      'The terminal status line is off; suggestions now pop up in the overlay.',
      'Run `refluent overlay test` to see it and drag it where you want it.',
    ],
  };
}

export function uninstallOverlay(db: DatabaseType, options: OverlayInstallOptions): OverlayInstallResult {
  const { paths, run } = options;
```

```swift
// refluent overlay helper: a renderer only. Node decides what to show and sends one
// JSON object per line on stdin; this process reports drags and dismissals as JSON
// lines on stdout. It exits when stdin closes, so it never outlives its supervisor.
import AppKit

struct Position: Codable {
  let x: Double
  let y: Double
}

struct ShowMessage: Decodable {
  let rewrite: String
  let label: String
  let reason: String
  let original: String
  let durationMs: Double
  let position: Position?
}

func emit(_ object: [String: Any]) {
  guard let data = try? JSONSerialization.data(withJSONObject: object) else { return }
  FileHandle.standardOutput.write(data + Data("\n".utf8))
}

/// Never key, never main: the panel must not take focus from whatever the user is typing in.
final class OverlayPanel: NSPanel {
  override var canBecomeKey: Bool { false }
  override var canBecomeMain: Bool { false }
}

/// Owns every pointer interaction so labels never swallow a click: hover holds the panel,
/// a click toggles the expanded view, a drag moves it. Only the close button is exempt.
final class InteractionView: NSView {
  var onHover: (Bool) -> Void = { _ in }
  var onClick: () -> Void = {}
  var onDragEnd: () -> Void = {}
  weak var closeButton: NSButton?
  private var downInWindow: NSPoint?
  private var dragged = false

  override func acceptsFirstMouse(for event: NSEvent?) -> Bool { true }

  override func hitTest(_ point: NSPoint) -> NSView? {
    guard let hit = super.hitTest(point) else { return nil }
    if let button = closeButton, hit === button || hit.isDescendant(of: button) { return hit }
    return self
  }

  override func updateTrackingAreas() {
    super.updateTrackingAreas()
    trackingAreas.forEach(removeTrackingArea)
    addTrackingArea(NSTrackingArea(
      rect: bounds, options: [.mouseEnteredAndExited, .activeAlways, .inVisibleRect], owner: self))
  }

  override func mouseEntered(with event: NSEvent) { onHover(true) }
  override func mouseExited(with event: NSEvent) { onHover(false) }

  override func mouseDown(with event: NSEvent) {
    downInWindow = event.locationInWindow
    dragged = false
  }

  override func mouseDragged(with event: NSEvent) {
    guard let window, let start = downInWindow else { return }
    let dx = event.locationInWindow.x - start.x
    let dy = event.locationInWindow.y - start.y
    if !dragged && abs(dx) < 3 && abs(dy) < 3 { return }
    dragged = true
    window.setFrameOrigin(NSPoint(x: window.frame.origin.x + dx, y: window.frame.origin.y + dy))
  }

  override func mouseUp(with event: NSEvent) {
    defer { downInWindow = nil }
    if dragged { onDragEnd() } else { onClick() }
  }
}

@MainActor
final class OverlayController: NSObject {
  static let width: CGFloat = 380
  static let margin: CGFloat = 16

  private let panel = OverlayPanel(
    contentRect: NSRect(x: 0, y: 0, width: OverlayController.width, height: 60),
    styleMask: [.nonactivatingPanel, .borderless], backing: .buffered, defer: false)
  private let root = InteractionView()
  private let stack = NSStackView()
  private let rewriteLabel = OverlayController.label(size: 14, weight: .semibold, color: .labelColor)
  private let detailLabel = OverlayController.label(size: 12, weight: .regular, color: .secondaryLabelColor)
  private let originalLabel = OverlayController.label(size: 12, weight: .regular, color: .tertiaryLabelColor)
  private let closeButton = NSButton(title: "×", target: nil, action: nil)
  private var message: ShowMessage?
  private var position: Position?
  private var expanded = false
  private var hovering = false
  private var hideTimer: Timer?
  /// Bumped on every show, so a fade that finishes after a newer show never hides it.
  private var generation = 0

  override init() {
    super.init()
    panel.level = .statusBar
    panel.collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary, .stationary, .ignoresCycle]
    panel.isOpaque = false
    panel.backgroundColor = .clear
    panel.hasShadow = true
    panel.hidesOnDeactivate = false
    panel.becomesKeyOnlyIfNeeded = true

    let effect = NSVisualEffectView()
    effect.material = .hudWindow
    effect.blendingMode = .behindWindow
    effect.state = .active
    effect.wantsLayer = true
    effect.layer?.cornerRadius = 10
    effect.layer?.masksToBounds = true
    effect.translatesAutoresizingMaskIntoConstraints = false

    stack.orientation = .vertical
    stack.alignment = .leading
    stack.spacing = 4
    stack.edgeInsets = NSEdgeInsets(top: 10, left: 12, bottom: 10, right: 28)
    stack.translatesAutoresizingMaskIntoConstraints = false
    for view in [rewriteLabel, detailLabel, originalLabel] { stack.addArrangedSubview(view) }

    closeButton.isBordered = false
    closeButton.font = .systemFont(ofSize: 13)
    closeButton.contentTintColor = .secondaryLabelColor
    closeButton.target = self
    closeButton.action = #selector(closeClicked)
    closeButton.translatesAutoresizingMaskIntoConstraints = false

    root.addSubview(effect)
    root.addSubview(stack)
    root.addSubview(closeButton)
    root.closeButton = closeButton
    NSLayoutConstraint.activate([
      effect.leadingAnchor.constraint(equalTo: root.leadingAnchor),
      effect.trailingAnchor.constraint(equalTo: root.trailingAnchor),
      effect.topAnchor.constraint(equalTo: root.topAnchor),
      effect.bottomAnchor.constraint(equalTo: root.bottomAnchor),
      stack.leadingAnchor.constraint(equalTo: root.leadingAnchor),
      stack.trailingAnchor.constraint(equalTo: root.trailingAnchor),
      stack.topAnchor.constraint(equalTo: root.topAnchor),
      stack.bottomAnchor.constraint(equalTo: root.bottomAnchor),
      stack.widthAnchor.constraint(equalToConstant: OverlayController.width),
      closeButton.topAnchor.constraint(equalTo: root.topAnchor, constant: 6),
      closeButton.trailingAnchor.constraint(equalTo: root.trailingAnchor, constant: -8),
    ])
    panel.contentView = root

    root.onHover = { [weak self] inside in
      self?.hovering = inside
      self?.restartTimer()
    }
    root.onClick = { [weak self] in
      guard let self else { return }
      self.expanded.toggle()
      self.render()
      self.restartTimer()
    }
    root.onDragEnd = { [weak self] in
      guard let self else { return }
      let frame = self.panel.frame
      self.position = Position(x: frame.minX, y: frame.maxY)
      emit(["type": "moved", "x": frame.minX, "y": frame.maxY])
      self.restartTimer()
    }
  }

  private static func label(size: CGFloat, weight: NSFont.Weight, color: NSColor) -> NSTextField {
    let field = NSTextField(wrappingLabelWithString: "")
    field.font = .systemFont(ofSize: size, weight: weight)
    field.textColor = color
    field.isSelectable = false
    field.preferredMaxLayoutWidth = width - 40
    return field
  }

  func show(_ next: ShowMessage) {
    generation += 1
    message = next
    if let stored = next.position { position = stored }
    expanded = false
    render()
    panel.alphaValue = 1
    panel.orderFrontRegardless()
    restartTimer()
  }

  private func render() {
    guard let message else { return }
    rewriteLabel.stringValue = message.rewrite
    detailLabel.stringValue = message.reason.isEmpty ? message.label : "\(message.label): \(message.reason)"
    originalLabel.stringValue = message.original
    originalLabel.isHidden = !expanded || message.original.isEmpty
    let lines = expanded ? 0 : 2
    rewriteLabel.maximumNumberOfLines = lines
    detailLabel.maximumNumberOfLines = lines
    root.layoutSubtreeIfNeeded()
    let height = ceil(stack.fittingSize.height)
    let top = topLeft()
    panel.setFrame(
      NSRect(x: top.x, y: top.y - height, width: OverlayController.width, height: height), display: true)
  }

  /// The stored top-left corner while any part of it is on a connected screen; otherwise the
  /// top-right of the main screen (an unplugged display must not strand the panel off-screen).
  private func topLeft() -> NSPoint {
    if let stored = position {
      let probe = NSRect(x: stored.x, y: stored.y - 40, width: OverlayController.width, height: 40)
      if NSScreen.screens.contains(where: { $0.visibleFrame.intersects(probe) }) {
        return NSPoint(x: stored.x, y: stored.y)
      }
    }
    let screen = (NSScreen.main ?? NSScreen.screens.first)?.visibleFrame
      ?? NSRect(x: 0, y: 0, width: 1440, height: 900)
    return NSPoint(
      x: screen.maxX - OverlayController.width - OverlayController.margin,
      y: screen.maxY - OverlayController.margin)
  }

  private func restartTimer() {
    hideTimer?.invalidate()
    hideTimer = nil
    guard !expanded, !hovering, panel.isVisible, let message else { return }
    hideTimer = Timer.scheduledTimer(withTimeInterval: max(1, message.durationMs / 1000), repeats: false) {
      [weak self] _ in
      MainActor.assumeIsolated { self?.fadeOut(duration: 0.3) }
    }
  }

  private func fadeOut(duration: TimeInterval) {
    hideTimer?.invalidate()
    hideTimer = nil
    let current = generation
    NSAnimationContext.runAnimationGroup({ context in
      context.duration = duration
      self.panel.animator().alphaValue = 0
    }, completionHandler: { [weak self] in
      MainActor.assumeIsolated {
        guard let self, self.generation == current else { return }
        self.panel.orderOut(nil)
      }
    })
  }

  @objc private func closeClicked() {
    emit(["type": "dismissed"])
    expanded = false
    hovering = false
    fadeOut(duration: 0.1)
  }
}

let app = NSApplication.shared
app.setActivationPolicy(.accessory)
// Top-level code runs on the main thread; say so, since this file is not main.swift.
let controller = MainActor.assumeIsolated { OverlayController() }

Thread.detachNewThread {
  let decoder = JSONDecoder()
  while let line = readLine() {
    guard let message = try? decoder.decode(ShowMessage.self, from: Data(line.utf8)) else { continue }
    DispatchQueue.main.async { MainActor.assumeIsolated { controller.show(message) } }
  }
  DispatchQueue.main.async { NSApp.terminate(nil) }
}

app.run()
```
